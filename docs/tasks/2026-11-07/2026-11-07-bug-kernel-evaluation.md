# 算子评测修复验收

类型为缺陷修复。目标是让重试、可变输入和本地执行权限都符合评测契约。可变输入的证据布局见[计时设计](../../design/2026-11-07/2026-11-07-kernel-mutable-input-timing.md)。

验收覆盖三条路径。用可控的 msprof 重现失败尝试遗留证据，用设备替身与原始 trace 夹具检验计时归属，并由真实子进程检查凭据隔离。最后运行类型检查、构建与默认测试集。

## 实际结果

- Evaluator 在 Node.js 24.22.1、pnpm 11.22.0 上通过类型检查和构建。默认测试共 2,214 项通过，67 项跳过，2 项失败。另在干净的 `cf3d80a` 上单独复现同样两项失败：Hermes 运行时缺少测试预期的两个镜像环境变量，AgentX 不可达主机采样超过 5 秒。
- 使用 CPU PyTorch 2.13 运行严格检查、计时与 replay 的 31 项 Python 测试，全部通过。其中覆盖重复张量参数、重叠切片、零步长视图、跨调用隔离，以及准备耗时不计入均值。
- SDK 和独立 CLI 的五条候选进程路径均验证了环境变量过滤。失败的采集遗留完整证据、重试无产出时，返回采集不可用。成功重试只归属本轮采集的指标。
- 本地打包 Evaluator，将包内构建产物用于 RSI 工作树的 `pnpm check`，633 项测试通过，3 项跳过。RSI 清单仍锁定原有 SDK 提交。
- 本机未运行 Ascend NPU、真实 CANN profiler 或模型请求。真机正确性、延迟与加速比待验收。
