# 工作流网络资源

日期：2026-11-10

状态：用户已明确批准 network.runtime 方案。补充 [工作流实施设计](2026-11-10-workflow-runtime-implementation.md)。

- 网络资源保存未展开模板，按已声明名称异步读取执行节点环境及凭据，创建并释放 NetworkRuntime。模型客户端、Benchmark 工厂借用该资源，不再各自创建网络客户端。
- --network 加载模板并装配显式资源依赖；导出与保存计划保留模板，不保存代理认证值。默认配置沿用现有网络文件选择规则。显式网络资源绑定保持用户选择。
- 协调端长期资源依赖 run 网络资源；节点模型等资源依赖 worker 网络资源，避免跨进程传递客户端。
- 预热只允许创建提供者明确声明可用于准备阶段的依赖；其生命周期由预热操作结束时释放。网络资源允许这种使用，模型、容器等评测资源不允许。
- 恢复身份保存网络模板，资源恢复操作重新创建短期网络客户端并在结束时释放，不重新解释本机网络配置文件。
