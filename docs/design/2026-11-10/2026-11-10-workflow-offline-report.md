# 工作流离线报告

日期：2026-11-10

状态：用户已确认。补充工作流实施设计中的报告与结束阶段。

当前 `report` 只生成通用摘要，取消后普通报告步骤不执行，无法保留已有 Reporter 和报告历史。

- 步骤可声明离线报告接口，读取已保存的运行记录和产物。上下文不提供认证解析、运行资源或模型客户端；重新评分不属于报告操作。
- 保存报告步骤配置、实现版本及所需插件来源。离线加载只选择报告步骤及其声明的依赖，不要求其他模型、环境插件可用。
- 正常执行保留步骤内的报告输出；结束阶段在资源释放后生成入口报告。失败、取消时使用已提交的部分结果。显式 report 命令使用同一实现。
- Benchmark 的离线报告调用原 Metrics/Reporter，保留逐题证据链接。报告历史在运行目录保存：首次续跑归档初始报告，每次显式续跑新增快照；补测和离线重建更新当前报告。
- 报告失败单独记录并保留已提交评测结果，不重跑成功样例。没有离线报告插件时生成通用摘要。
- Ray Jobs 在协调端完成相同结束步骤，下载到提交端后按提交端部署的报告插件位置重建加载元数据；不把提交端 patch 路径发送给节点。

验收覆盖自定义 Reporter、无模型认证重建、取消后部分报告、版本变化拒绝、无关插件缺失、报告失败不丢结果、历史快照与 Ray 下载后重建。
