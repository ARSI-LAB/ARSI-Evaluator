# 资源插件维护操作

日期：2026-11-10

用户已批准：资源提供者声明维护操作，CLI 分发 doctor / cleanup-images，Benchmark 插件复用实际检查和清理逻辑，Jobs 转发相同请求。清理默认预览，只有 --execute 才删除镜像。

## 接口与执行

ResourceProvider 声明 maintenance 操作表。每项独立校验请求，接收静态资源配置和运行上下文，返回 JSON 结果。插件声明是否通过检查，应用层据此设置退出码。预热与维护共用静态资源遍历；只有显式允许的依赖客户端可创建，评测步骤、模型请求与评测状态均不执行。动态绑定无法解析时返回 deferred，不伪装为通过。依赖逆序释放，失败与取消也释放。

Benchmark 的运行资源声明 doctor 和 cleanup-images；按实际模型分组逐个检查或清理。清理只创建 Scheduler / Environment，避免访问模型或下载题库；诊断复用环境、运行时、来源路径及网络探测。网络检查通用 I/O 移到 infrastructure，Benchmark 选择检查目标，CLI 不判断 Benchmark 名称。

Jobs 使用 maintenance 请求携带操作名和参数，服务端重新编译计划并由插件校验参数；结果单独下载，不产生评测运行或接受续跑参数。凭据继续走现有内存通道，结果及日志脱敏。

## 验收

验证静态与动态绑定、插件操作缺失、依赖关闭、取消、无模型调用、清理预览及执行参数、CLI 退出码、Jobs 请求校验与结果读取。实际 Ray 验证使用本机 WSL 受控夹具。
