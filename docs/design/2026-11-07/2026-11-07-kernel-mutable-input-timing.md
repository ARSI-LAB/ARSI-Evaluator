# 可变输入算子的计时证据

严格契约允许候选修改输入。正确性检查、预热、正式计时和 MSTX 采集都应从同一组原始输入值开始。准备输入可能触发设备 kernel，复制耗时计入均值会改变候选排名。

对于 `inputUnmodified: false`，计时器在准备步骤复制本轮所需输入并同步设备，再在执行步骤运行算子。参考和候选遵循同一布局。每次仅准备当前调用所需的输入，设备内存用量不随采样次数增长。MSTX 采集在输入准备完成后开启正式区间。

新计时样本以 `stepLayout: "prepare-then-run"` 声明交替步骤。审计器使用冻结任务契约验证该布局，利用原始 CSV 和 trace 的因果关联检查设备记录，再按执行步骤重算均值。已有样本沿用其原有步骤解释，便于离线报告与复核。

本设计的验收边界是输入值、区间顺序、证据归属和旧样本兼容性。真实设备对 profiler 的支持与实测算子速度需另行验证。
